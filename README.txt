ЗАГАДКА ДРЕВНЕГО ХРАМА — мобильная 3D-игра

ЗАПУСК:
1. Откройте index.html в современном браузере с подключением к интернету.
2. Для публикации используйте GitHub Pages:
   - создайте новый публичный репозиторий на github.com;
   - загрузите index.html в корень репозитория;
   - откройте Settings → Pages;
   - в разделе Build and deployment выберите Deploy from a branch;
   - выберите ветку main и папку /(root), затем Save.
3. Через некоторое время GitHub покажет ссылку вида:
   https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/

ИГРА:
- Джойстик слева — движение.
- Проведение пальцем по экрану — обзор.
- Подойди к трём круглым символам и нажми «ВЗАИМОДЕЙСТВИЕ».
- Подсказки дают цифры кода 427.
- Подойди к двери, нажми взаимодействие и введи 427.

ПРИМЕЧАНИЕ:
Three.js загружается с CDN, поэтому при первом запуске нужен интернет.
Это первая демонстрационная версия; для дальнейшего развития можно добавить новые комнаты,
анимации, звуки, инвентарь и сохранение прогресса.
